# Muhammad Usama Tariq | Engineering Portfolio

Welcome to the repository for my personal portfolio website. I am an **Erasmus Mundus meta4.0 Scholar** combining a foundation in mechanical engineering with advanced expertise in sustainable, intelligent manufacturing. 

This repository houses the front-end code for my live portfolio, which highlights my transition of complex mechanical concepts into optimized, manufacturable realities.

**🔗 [View the Live Website Here](https://Usama-Tariq.github.io)**

### Key Features of this Repository
* **Live Telemetry Simulation:** Custom vanilla JavaScript implementation of a 3-Degree-of-Freedom (3-DOF) PID closed-loop kinematic monitor, simulating real-time DAQ hardware feedback.
* **Project Showcase:** Detailed breakdowns of my work, including topology optimization, material selection (Granta), and high-performance structural design.
* **Responsive UI:** A lightweight, dark-themed interface built with raw HTML/CSS for maximum performance and zero dependency bloat.

### Technology Stack
* HTML5
* CSS3
* Vanilla JavaScript (Canvas API for telemetry rendering)
